# しまなつ

白砂島で過ごす、高校二年の夏休みシミュレーター（PS2風のローポリ3D）。

## 遊び方
このフォルダで次を実行し、ブラウザで http://localhost:8123 を開く。

    python3 tools/serve.py 8123

### 操作
- 移動：WASD／矢印　走る：Shift　視点：マウスドラッグ・Q/R　視点切替（三人称／一人称）：V
- 話す・調べる・乗る：E（Enter・Zでも可。一時停止画面で変更可能）　ジャンプ：スペース
- 写真：P（その日の日記に残る。何度でも撮り直し可）　メニュー（地図・持ち物・準備状況）：M　一時停止・設定：Esc
- 自転車・原付：近くでEで乗る。WASD／矢印でこぐ（原付は走る）。Bで降りる（翌朝は元の場所に戻る）
- 軽トラ：近くでEで運転、Bで降りる。運転操作（かんたん・マニュアル・ラジコン）は一時停止画面で選べる
- 会話：画面右側の縦書き。E／スペース／Enterで全文表示・ページ送り・次のセリフへ。返事は上下／W・S、Tab、クリックで選べる

### 島での過ごし方
- **学校**：昇降口から暗転なしで出入りできる。3階の教室で文化祭の準備を進めるほか、音楽室・図書室・美術室・保健室なども調べられる
- **家・商店・空港**：自宅ではテレビ・扇風機・麦茶やスイカ・昼寝・本棚の振り返り、机で「これまでの絵日記」の読み返しもできる。しおかぜ商店ではラムネ・アイス・だがし・道具（傘・虫取り網・浮き輪・麦わら帽子）、空港の待合室では遊覧飛行（自分で操縦も可）が楽しめる
- **島あそび・行事**：釣り、水切り、セミ取り、磯のカニさがし、足湯、おみくじ、自販機、サッカー、飛び込み、夜の展望台での星座さがし、沖の小島への遠泳。ラジオ体操、盆踊り、台風、線香花火、最終日の花火まで12日間の夏休みを過ごす
- **保存**：毎朝、自動で記録される。「つづきから」はその日の朝から再開。一時停止画面の「AIのセリフ（試験）」をONにすると、WebGPU対応ブラウザでローカルLLMによる会話も試せる

## 作り直し
- モデル：`/Applications/Blender.app/Contents/MacOS/Blender -b -P blender/characters.py`（`buildings.py`、`props.py`、`school_in.py` も同じ）。`models/*.glb` に書き出される。
- 自転車だけを再生成：`/Applications/Blender.app/Contents/MacOS/Blender -b -P blender/bicycle.py`。
- 校舎の間取り：`python3 blender/school_layout.py` で `data/school-layout.js` を更新する。
- テクスチャ：`tools/gen_textures.sh <バッチ名>` で `textures/src/` に生成し、`tools/sync_textures.sh` が512pxに縮小して `textures/` に置く。プロンプトは `gen_textures.sh` の中にある。
- セリフとイベントの文章：`data/story.js`、`data/talk.js`
